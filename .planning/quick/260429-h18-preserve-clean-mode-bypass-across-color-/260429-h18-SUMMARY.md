# Quick Task 260429-h18: Preserve Clean Mode Bypass Across Color Slider Changes

**One-liner:** Added `bypassed?: boolean` flag to `AudioVoice` so `updateVoiceColor` skips filter/waveshaper overwrites when Clean mode is active.

## What Was Built

Three minimal edits to `src/engine/audioEngine.ts`:

1. `AudioVoice` interface gains `bypassed?: boolean` — tracks whether Clean mode is currently active for a voice.
2. `setVoiceDistortionBypass` sets `voice.bypassed = bypass` after updating the audio nodes, so the flag always reflects the current bypass state.
3. `updateVoiceColor` guards both the `filter.frequency.setTargetAtTime` call (with `!voice.noiseSource && !voice.bypassed`) and the `waveshaper.curve` assignment (with `!voice.bypassed`). The oscillator frequency update is left unconditional so hue-to-pitch still works in Clean mode.
