<objective>
Preserve the Clean mode bypass state when color sliders change.

Purpose: `updateVoiceColor` unconditionally overwrites `voice.filter.frequency` and
`voice.waveshaper.curve` on every color change. When the user has activated Clean mode
(via `setVoiceDistortionBypass(id, true, ...)`), those overwrites silently defeat the
bypass. Tracking `bypassed` on the voice itself lets `updateVoiceColor` skip the
filter and waveshaper writes while still allowing the oscillator frequency (hue → pitch)
to update normally.

Output: Modified `src/engine/audioEngine.ts` with `bypassed?: boolean` on `AudioVoice`,
set/cleared in `setVoiceDistortionBypass`, and guarded in `updateVoiceColor`.
</objective>
