# Quick 260429-g90: Bypass Filter in Clean Mode Summary

**One-liner:** Filter cutoff raised to 20000 Hz (fully open) when Clean toggle is active, restoring to lightness-derived cutoff on deactivate — truly clean oscilloscope readout.

## What Was Done

The "Clean" button in CellPanel previously only bypassed the waveshaper distortion. The lowpass filter was still shaping the signal, causing the oscilloscope to show a rounded waveform even in Clean mode. This task extends the bypass to also open the filter to 20000 Hz when Clean is active, giving a genuinely flat/unfiltered waveform reading.

## Changes

### src/engine/audioEngine.ts

- `setVoiceDistortionBypass` signature extended: `(shapeId, bypass, saturation?, lightness?)`
- `lightness` defaults to `50` (neutral cutoff ~894 Hz) when not supplied
- `bypass=true`: sets `voice.filter.frequency.value = 20000`
- `bypass=false`: sets `voice.filter.frequency.value = lightnessToFilterCutoff(lightness)`
- Direct assignment used (no `setTargetAtTime`) — correct for a button press action

### src/components/CellPanel.tsx

- `useEffect` shape-switch reset: `setVoiceDistortionBypass(shape.id, false, shape.color.s, shape.color.l)`
- `handleCleanToggle`: `setVoiceDistortionBypass(shape.id, next, shape.color.s, shape.color.l)`
