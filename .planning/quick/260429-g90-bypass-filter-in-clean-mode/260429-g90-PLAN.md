New body (keep the waveshaper line, add filter lines below it):
```typescript
  const voice = voices.get(shapeId)
  if (!voice) return
  voice.waveshaper.curve = bypass ? null : makeDistortionCurve(saturation)
  // Also bypass / restore the filter so the waveform is truly clean (g90)
  // bypass=true  → 20000 Hz (effectively open / transparent for the oscilloscope range)
  // bypass=false → restore to lightness-derived cutoff
  voice.filter.frequency.value = bypass ? 20000 : lightnessToFilterCutoff(lightness)
```

Do NOT touch blob voices specially — the blob voice's filter is a bandpass centred on pitch,
not a lowpass. Setting it to 20000 Hz when Clean is active is acceptable for the waveform
display; the blob sound is unusual anyway. The existing guard in `updateVoiceColor` that skips
blob filter updates is unrelated to this bypass path.

Do NOT use setTargetAtTime here — direct assignment is correct (instant visual effect for
the oscilloscope; no audio click risk because the user just pressed a button, not a
continuous automation).
